# Architecture Decision Records

Each significant technical decision is recorded as a short ADR.

## Conventions

- File name: `NNNN-short-title.md` (e.g. `0001-select-static-site-stack.md`), numbered sequentially.
- Status: `Proposed`, `Accepted`, or `Superseded by NNNN`.
- ADRs are not edited after acceptance; supersede them with a new record instead.

## Template

```markdown
# NNNN. Title

- Status: Proposed
- Date: YYYY-MM-DD

## Context

What problem or constraint prompts this decision?

## Decision

What was decided?

## Consequences

What becomes easier or harder as a result?
```
